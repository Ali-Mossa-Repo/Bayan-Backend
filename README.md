# Bayan

Developed a notation application for efficient creation, organization, and management of notes and information 

## Features

- Create, edit, and delete notes efficiently
- Organize notes using categories or tags for better structure
- Fast search and retrieval of saved notes
- User-friendly interface for seamless note management
- Designed clean and user-friendly UI/UX interfaces and performance optimization


## Technologies Used

### Frontend
- React

### Backend
- node.js

### Database
- Postgres

### Tools
- Git & GitHub
- Postman
- VS Code
